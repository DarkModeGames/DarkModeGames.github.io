All entity types

One row per entity type. The first link goes to its fields in the generated reference; the second to the page that shows it in use.

Entity What it is for Learn it
Action One step of game logic: an optional if, a do function with parameters, then then / else. guide
Actor Anything that stands in the world: players, monsters, NPCs, props. guide
Animation One clip: frame lists for all eight directions, speed, looping, an optional sound. guide
AnimationSet The clips a sprite can play, and which ones play when idle, walking and running. guide
Behavior One step of a Strategy: goals, and the action to run while they are not met. guide
Condition A comparison of two dice expressions, used as an action's if or a behavior's goal. guide
Deployment Places an actor on a map at a Vector when the world is built. guide
Dialog A titled text panel shown to the player; text can show live values. guide
Face Which of a tile's six faces count as walkable, wall or boundary. guide
Floor A picture drawn under a map's tiles at a Vector. guide
Group A faction with a name and outline colour; used for targeting by group. guide
Inset Padding on a sprite frame's four edges; seats the art's feet on the ground. guide
Layer One grid of tile symbols in a TileMap. guide
Main The campaign's entry point: the starting map and the players' starting actor. guide
Map A playable area: its tiles, spawn point, deployments, background, overlays and audio. guide
Mask Swaps one colour for another inside a Skin. guide
Measure A value worked out from a dice expression each time it is read. guide
Menu A list of actions offered as options in the interaction panel. guide
Nav An extra point where walkers may bend their path, such as a doorway. guide
Overlay A full-screen animated effect between the world and the interface, such as rain. guide
Parallax A scrolling background layer behind a map. guide
Parameter A key and value passed to an action's function. guide
Particle A small animated sprite attached to one actor, such as a glow. guide
Resource A stored number every actor holds: health, gold, an item count, a flag. guide
Skill A hotbar ability: the action run on press, an optional one on release, and an optional charge. guide
Skin A list of Masks that recolours an actor's sprite. guide
Sound An audio file with looping and pitch, for a map's ambience or an animation. guide
Sprite A sprite sheet: texture, frame size, margin and its AnimationSet. guide
Strategy An NPC's AI: an ordered list of Behaviors. guide
Tile One cell type in a TileSet: its symbol, picture and faces. guide
TileMap A map's ground: a TileSet and its Layers. guide
TileSet A tile atlas texture and the Tiles cut from it. guide
Timer Runs an action on an actor every interval seconds. guide
Trigger Runs an action whenever one of the actor's Resources changes. guide
Vector A position (x, y) on a map, or a size. guide
Waypoint A discoverable, named place on a map, with an optional menu for fast travel. guide
