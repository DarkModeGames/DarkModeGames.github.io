## Running it

Put the Isometry executable in a folder, place your campaign `.zip` files alongside it, and
launch with command line arguments:

<div>
<a href="/reference/cli.html">
Command Line Reference
</a>
</div>

- **Linux** — mark the binary executable, then run it.
- **Windows** — run the `.exe` (double-click, or launch from a terminal to pass flags for
  hosting and dedicated servers).
- **macOS** — if Gatekeeper quarantines the app, clear it with
  `xattr -dr com.apple.quarantine Isometry.app`, then open it.
