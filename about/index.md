# About Isometry

{{ product_name }} is a data-driven isometric RPG framework by **{{ publisher }}**. A single
executable loads campaigns defined entirely in YAML or JSON, so you build a game
by writing data, not code. Multiplayer is built in and driven from the command line.

Isometry is currently in **open beta**, version **{{ version }}**.
